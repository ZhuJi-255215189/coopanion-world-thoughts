# coopanion-world-thoughts

给 Coopanion 加一页「思维链」：她在这轮回答之前想了什么、想到哪了、什么时候开口。

面板里每一段推理前面都有同一个符号 **✻**；模型每吐一段推理，那一行就往下长；她开始说正文，
这一段就收起来，进到「再往前」里。只观察，不打断，不改她的回答。

思维链是模型自己写的，很多时候是英文。看不懂就点一下 **译**，或者勾上「自动译」，
插件会用你当前配置的模型把这一段翻成中文，原文留在上方对照。

## 它显示什么

| 面板上的东西 | 来自哪里 |
|---|---|
| `✻ 正在想` + 正在长的正文 | 主 session 每一轮模型输出里的 `response.reasoning.*` 增量 |
| `已开口` | 这一段之后模型开始输出正文（`response.output_text.delta`） |
| `中断` | 这一轮被 preempt / interrupt 取消 |
| `已截断` | 这一段超过「单段最多多少字」，尾巴没保留 |
| `译` / 中文译文 | 插件另调一次模型，把这一段翻成简体中文 |
| `再往前` | 最近若干段，点开看全文 |

面板顶部还能暂停记录、清空、复制最近一段。暂停只停记录，已经记下的照常能看。

## 为什么不会改变她的回答

它是 World 层的**旁路**：挂在 Core 的 `OutputTap` 上（`World.outputTap`），只收流事件，
不发事件、不注册工具、不写环境提示词（`envPromptVars()` 返回 `null`）。

- 思维链只在面板里出现，**不会进入对话上下文**，下一轮模型看不到它们；
- 不改变「模型已经开口」的判定（`externalizes` 恒为 `false`），打断与 preempt 照旧；
- 卸载这个 World，一切恢复原样，宿主代码一行没动。

## 安装

### 桌面端（官方 Electron 客户端）

在 Coopanion 的**扩展市场**里用「从本地目录安装」，指向本目录；或者在本机开发时直接把目录链进去：

```powershell
# 在 <数据目录>\extensions 里执行
pnpm add link:C:\path\to\coopanion-world-thoughts
```

扩展装在 `extensions/` 下，**装完要重启 Coopanion**。重启后到 World 页签打开「思维链」，
然后正常和她说一句话，面板里就会出现她刚才想的。

如果要发布到扩展市场，把 `package.json` 的 `repository` / `homepage` 换成你自己的地址，
再按市场的规则打包上传即可。

### 需要什么

- Coopanion ≥ 0.2.20（World API 6）
- Node ≥ 22
- 一个会返回思维链的端点：有些服务只给正文（reasoning 为空），那种情况下面板会一直空着

## 面板

`World` 页签 → 「思维链」：

1. 顶部的灯：`正在想` / `空闲` / `已暂停`；
2. 中间是最近一段，实时长字，贴底时自动跟着滚；
3. 下面是更早的段，点开看全文；
4. 「暂停记录」「清空」「复制最近一段」都在顶栏；
5. 每段右上角有个「译」；顶栏的「自动译」打开后，每段收尾自动翻。

## 桌宠上的思考气泡（可选补丁）

不想打开面板、只想在桌面上看她边想边说？可以给 Coopanion 自带的桌宠打一个小补丁：
她思考时，头顶的**活动气泡**（状态气泡）显示中文思考的**最后一句**（约 60 字以内，可换行）。

**优先用中文原文**：配合「思考中文」World（同工作区的 `coopanion-world-think-chinese`），
模型直接用中文推理，气泡在推理增量到达时就更新——**0 次额外调用、0 翻译延迟**。
没装它、或某一段仍是英文时，才用插件译好的中文兜底（「自动译」/手动「译」）。

切句是纯文本处理：按中英文句末标点（`。！？!?…`、后面跟空白/结尾的 `.`）和换行切句，
取最后一句；超过约 60 字就按逗号/分号等分句边界再收。气泡本身**不调用模型、不花额外 token**。

```powershell
# 在插件目录下
powershell -ExecutionPolicy Bypass -File scripts/patch-pet-bubble.ps1
# 还原
powershell -ExecutionPolicy Bypass -File scripts/patch-pet-bubble.ps1 -Revert
```

打的是 `cortico-world-desktop-pet` 的 `src/status.ts` 与 `web/pet.css`，改完**重启 Coopanion** 生效。

它和对话是分开的：

- 走的是活动气泡（status），不是说话气泡；**不进聊天记录，也不进对话上下文**；
- 不经过 `say` / `said`，所以语音（大肥鱼等）**不会朗读**思考内容；
- 她一开始说正文，思考文本立刻清空，气泡让位给对话；
- 只有"状态气泡"开关打开时才显示（`worlds.desktop-pet.statusBubble`，默认开）。

并且和本插件**绑定**：只有插件在运行时气泡才显示思考；在面板里「暂停记录」，或者把 World 停用/卸载，
气泡就退回只有思考图标（插件和桌宠 World 在同一个 core 进程里，用一个共享标记即时联动，不加文件、不加模型调用）。

注意：Coopanion 升级会覆盖 `node_modules` 里的宿主文件，升级后重跑一次脚本即可。
脚本是幂等的；源码版本对不上时它会拒绝改动，不会写坏文件。

气泡里的中文来自两条路：

1. **原文就是中文**（装了「思考中文」，或模型本来就用中文想）：推理增量一到就写进气泡，
   实时更新，不等翻译；
2. **原文是英文**：沿用插件已经译好的中文（自动译/手动「译」），不会为了气泡再调一次模型。

第一段还没有中文时显示「正在想…」；不会空着，也不会先闪英文再跳中文。
手动「译」最新一段也会更新气泡；翻旧段不会让气泡倒退。

## 看不懂英文？

如果你发现自己**总在点「译」**，那更值得先装同系列的 **「思考中文」**（`coopanion-world-think-chinese`）：
它往每一轮的系统前缀里塞一句「内部思考一律用简体中文」，模型直接用中文推理，这个面板和桌宠气泡读到的
就是中文原文——不用翻、不花额外调用、也没有翻译延迟。

分工一句话：**思考中文管「怎么想」，思维链管「怎么显示」**。两个都装才最好用；只装思维链也能用，
英文段照样能一键译。

两种用法：

- **按需**：点某一段的「译」——只翻那一段，花多少算多少；
- **自动**：勾上顶栏「自动译」——每段收尾后各翻一次。这个开关写进 `worlds.thoughts.autoTranslate`，会一直保持。

翻译走 Coopanion 当前激活的 provider（就是主模型那个端点），用同一把密钥，不需要另配。
请求里显式关掉了 reasoning，不会因为翻译再多想一遍；用量记进 usage 账本，label 是「思维链翻译」。

原文已经是中文的段**不会**再调模型（直接沿用原文）；只有英文段才真正发请求，
所以配合「思考中文」时，翻译开销基本为零。

代价：每段多一次输出。按 deepseek-flash 的价，一段几百 token 的思考，翻译大约几厘钱。
不想花就关掉「自动译」，只手动点。

译文只存在内存里，重启 Coopanion 就没；原文永远保留。

## 看不到内容？

按顺序排查：

- **端点不给思维链**：很多 OpenAI 兼容端点不开 reasoning；面板会一直空着，这不是插件坏了。
  在主模型设置里打开「开启推理」，或换一个会返回 reasoning 的模型。
- **暂停记录**开着：顶栏会显示「已暂停」。
- **World 没启用**：World 页签里「思维链」要处于激活状态。
- **装完没重启**：扩展的定义是启动时导入的，必须重启 Coopanion。

## 配置项（`config.json` 的 `worlds.thoughts`）

| 键 | 默认 | 说明 |
|---|---|---|
| `maxBlocks` | `40` | 面板里最多留几段；更早的丢掉。 |
| `maxChars` | `20000` | 单段最多留多少字符；超出的尾巴不保留，面板标「已截断」。 |
| `paused` | `false` | 暂停记录。 |
| `autoTranslate` | `false` | 每段收尾后自动翻成中文；中文段直接沿用原文、不调模型；关着时仍可手动点「译」。 |

`enabled` 由 World 页签的开关维护。

## 隐私

- 插件本身不联网、不写文件、不读文件；思维链与译文都只在进程内存里，重启即清。
- 只有你点「译」或开着「自动译」时，这一段原文才会发给当前激活的 provider（和她的对话走同一个端点、同一把密钥）；不翻译就不外发。
- 思维链可能包含模型的内部推理；面板是给你自己看的，不会进对话，也不会发给别的服务。

## 开发

```powershell
npm test   # 纯逻辑：开段、收尾、截断、裁剪、流事件识别
```

`npm test` 用 `node --experimental-strip-types`，不需要构建；`webui/client.js` 是手写的纯 ESM，
也没有构建步骤。

还有一份离线冒烟（不启动 Coopanion，借它自带的 tsx 加载 World、喂假事件、检查面板快照与推流帧）。
它会真打一次翻译（几分钱），用来验证端点解析与译文清理。在 Coopanion 的 `resources/app` 目录下跑，
好让 `tsx` 解析得到：

```powershell
node --import tsx <本插件目录>\scripts\probe.mjs
```
